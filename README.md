# 群消息工作台

本项目是一个本地运行的群消息处理工作台，用于把消息接收、上下文整理、分类、人工审核和后续业务流转放在同一个界面中。

## 功能概览

- 从配置的消息来源接收实时消息并补读历史消息，按来源标识去重。
- 关联客户与群内回复，按对话上下文展示消息。
- 使用可解释规则、FAQ 和业务资料生成分类与处理建议，提供人工审核队列。
- 归档图片，并支持将审核后的内容交给飞书相关工作流处理。
- 默认不自动向群发送消息或执行撤回；外部写入由工作台中的人工操作触发。

## 本地启动

需要 Python 3.10 或更新版本。

```powershell
py -m pip install -r requirements.txt
```

将 `.env.example` 复制到项目的工作区根目录（本项目上一级目录）并在本机填写凭证。已有 `.env` 时不要覆盖它。然后在项目目录运行：

```powershell
.\start-workbench.ps1
```

打开 <http://127.0.0.1:8799/>。工作台只绑定本机回环地址，不是已部署的公网服务。

## 配置与数据保护

- 消息来源账号、规则标识及第三方服务凭证只放在本机 `.env`，不要提交到 GitHub。
- 飞书文案、排期、图库和业务表地址在工作台中配置；新安装默认不附带特定租户的资料源。
- 运行数据库、图片、报告和同步状态保存在 `data/` 等本地目录，已由 `.gitignore` 排除。不要公开真实客户消息、图片、令牌或签名链接。
- 分享代码前检查 Git 跟踪文件和提交历史；修改 `.gitignore` 后也要确认敏感文件没有被 Git 跟踪。
